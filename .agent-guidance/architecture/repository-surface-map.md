## Explicit Exclusions

The hosted SaaS marketing and internal admin app surfaces are intentionally removed from Roomote:

- `apps/admin/`
- `apps/marketing/`

The public product documentation is **not** excluded: it lives in `apps/docs/` as a self-contained Mintlify workspace published at [docs.roomote.dev](https://docs.roomote.dev). See [Web Dashboard](../features/web-dashboard.md) and [Public Docs Site](../features/public-docs-site.md).
