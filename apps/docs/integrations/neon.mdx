Connect Neon when Roomote needs to query or manage your Neon projects while it
investigates, plans, or implements a change.

## When to use it

- Inspect database state while debugging
- Answer schema or data questions tied to a task
- Create or manage projects and branches, run SQL, or change schemas and data

## How setup works

Admins enable Neon from **Settings > Integrations**. Each teammate then links
their own Neon account from [Personal Settings](/personal-settings) when they
need it.

## What to expect

Neon exposes mutating tools as well as read access. Neon recommends using its
MCP server only with development and testing projects, not production data.
Review tool calls carefully and limit the connected account to the projects the
task needs.
