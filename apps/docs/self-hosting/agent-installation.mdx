---
title: Local Docker setup for agents
description: Start Roomote locally with Docker Compose and a temporary HTTPS tunnel.
---

Use this page to try Roomote locally on macOS, Windows, or Linux. You need Git
and Docker with the Compose plugin. Docker Desktop works on macOS and Windows.

## Start Roomote

Clone Roomote, open the repository root, and create an uncommitted `.env.local`:

```sh
cp .env.local.example .env.local
```

Add a random setup token so the public setup page is not open to other visitors:

```dotenv
SETUP_TOKEN=<random-value>
```

Start the local self-host stack:

```sh
docker compose --env-file .env.local -f docker-compose.yml -f docker-compose.self-host.yml -f docker-compose.compute-docker.yml up -d --build
```

This starts the Roomote app, API, controller, queues, PostgreSQL, Redis, MinIO,
preview proxy, and local Docker task runtime. Open
`http://localhost:13000/setup` when no external HTTPS callback is needed.

## Add temporary HTTPS

OAuth and webhook providers need a public HTTPS URL. Create an uncommitted
`docker-compose.cloudflared.yml`:

```yaml
services:
  cloudflared:
    image: cloudflare/cloudflared:latest
    restart: unless-stopped
    command: tunnel --no-autoupdate --url http://web:3000
    depends_on:
      - web
```

Start the tunnel and read its URL:

```sh
docker compose --env-file .env.local -f docker-compose.yml -f docker-compose.self-host.yml -f docker-compose.compute-docker.yml -f docker-compose.cloudflared.yml up -d cloudflared
docker compose --env-file .env.local -f docker-compose.yml -f docker-compose.self-host.yml -f docker-compose.compute-docker.yml -f docker-compose.cloudflared.yml logs cloudflared
```

Find the generated `https://<random>.trycloudflare.com` URL in the logs. Set it
in `.env.local`:

```dotenv
R_PUBLIC_URL=https://<random>.trycloudflare.com
```

Recreate the stack so Roomote generates links and callbacks from that URL:

```sh
docker compose --env-file .env.local -f docker-compose.yml -f docker-compose.self-host.yml -f docker-compose.compute-docker.yml -f docker-compose.cloudflared.yml up -d --build
```

Use the generated HTTPS origin in provider configuration. Common callbacks are:

```text
GitHub callback: <origin>/github/callback
GitHub webhook:  <origin>/api/webhooks/github
Slack callback:  <origin>/api/slack/callback
Slack webhook:   <origin>/api/webhooks/slack
```

Open `<origin>/setup` and enter the `SETUP_TOKEN` from `.env.local`. Complete
provider sign-in and credentials in the browser, not in the agent conversation.

Quick Tunnel URLs are temporary. If cloudflared creates a new URL, update
`R_PUBLIC_URL`, recreate the stack, and update the provider callback URLs.

## Verify

Run the same Compose command with `ps` instead of `up -d --build`. Confirm the
long-running services are running, healthchecked services are healthy, and
`db-migrate` and `worker-image` exited successfully.
